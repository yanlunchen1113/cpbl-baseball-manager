遊戲的 110ms 接球闔合、捕手 140–280ms 打開、320–420ms 進入掌袋、430ms 握球，均為程序動畫調校值，並非由慢放影片量得的真實時間。

## 本次修正與限制

- 接球點由掌面幾何中心移到靠近虎口下方的掌袋；取球入口與球的依附點同步調整。
- 皮革、指墊、拇指側與繫帶使用兩階段形變；彎曲集中在指側，掌袋底部保留圓弧。手掌的握持形變也隨闔合改變。
- 球依附同一掌袋點，闔合不令球跳位；換手先打開，再由掌面取出。捕手、內野手、投手接回傳與接傳球者都套用。
- 這仍是程序形變與手掌控制，不是逐指骨骼、皮革碰撞或完整動作捕捉；不能宣稱每根手指都已具備獨立握力模擬。
- 程序检查覆盖左右手、入口走廊、闔合指側尺寸、持球連續與原有動作回歸；CPU 場景檢查不能代替 GPU 視覺檢查。
