## 實作與推估

- 主場樣式只套富邦主隊；每名球員的前、背號讀取遊戲的球員資料，不固定複製照片的 62 號。
- 前後圖案與側身、袖口映射在原蒙皮球衣；沒有放置懸浮的胸前隊名看板。藍色內搭使用同一骨架及手部 morph，避免肘部皮膚穿出。
- 胸前 wordmark 為依照片 2 用 imagegen 重製的透明點陣圖，並非官方提供的原始字標，也不宣稱刺繡字型逐像素一致。遊戲使用優化的 WebP。
- K.C.FAN、J.Y.TSENG 姓名可由照片辨識。其他球員若資料没有英文姓名，暫以中文姓名顯示，不猜英文縮寫。
- 藍色內搭目前用在照片可支持的范國宸、曾峻岳範例；球員臨場裝備配置仍可能不同。袖章簡化使用 G；細小品牌刺繡與布料摺痕尚未逐項還原。
- UV 尺寸與布料覆蓋範圍依現有模型估算；不是實測製衣版型。
