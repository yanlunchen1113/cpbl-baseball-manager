# 人物基礎細節修正（31.7）

搜尋 [MLB Josh Bell 握棒教學](https://www.mlb.com/video/bell-grip-for-hitters-c1451557583)及 [Rawlings 手套開口說明](https://www.rawlings.com/product/PROR204U-4N.html)。本次只讀取 MLB 頁面，未宣稱播放該影片。實際重新查看使用者11.18.54第2秒待打影格，以及 images-6 大谷手套、images-10 球員手套背面和 images-9 捕手回傳實拍：手套具腕部開口，手腕伸入而非整手消失；雙手握在細握柄而非跨過棒尾。

通用 MakeHuman 新增左右掌部控制骨，前臂末段至手掌漸變權重；依來源手指關節建立握柄軸與指根握持中心，避免只將掌心中心直接插入球棒。手腕採70度旋轉、20度額外偏轉上限，是遊戲控制限制，非每位球員量測。握柄中心距棒尾14cm，兩手仍相隔10cm，保留原有擊球後上手釋放及第一人稱棒路。

左右手指變形在手部及跨腕接縫三角形保持一致，避免分離網格一側彎曲另一側不動。手套手保留可見模型，新增背殼腕部開口及腕帶；朝向依實際手指軸，而非直接沿前臂延長線。球衣肩部沿共享位置平均法線增加最多8mm間隙；不刪皮膚頂點或隱藏手臂。尺寸、蒙皮區間與姿態為通用估計，尚非逐球員掃描或完整人體碰撞。
