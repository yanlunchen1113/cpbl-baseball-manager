## 修正與推估

- 曾峻岳手套側分手至前伸改為肩、肘 FK 路徑，該段肘部約 8 度微彎。方向、角度及前後銜接為對照畫面的手工推估，並非動態捕捉或實測解剖數據。
- 拿球手原本混合持續變動的舊 IK 目標和新 FK；舊 IK 的控制階段切換時，混合基準也跟著改變，造成瞬間移位。改為固定合手姿勢作為混合起點，再連續進入 FK。
- 手套手的混合起點同樣固定，避免在進入伸臂前產生新的跳動。左右投共用相應側的骨架；左投僅鏡像示意。
