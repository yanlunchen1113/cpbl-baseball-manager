# Blender 手套重建（2026-10-14）

## 實際查看的參考

主要採用使用者先前提供的照片，而非以模型自己作為參考：

- `images-18.jpeg`：一般手套正、背面。四指側有四條連續指槽；拇指獨立、虎口有球擋；掌袋是弧面，腕口位於背面下方。
- `images-19.jpeg`：實際佩戴。手腕從底部進入，手背在腕口內可見；不能把整隻手露在皮殼外。
- `images-10.jpeg`：投手實穿，封閉式球擋、四指背面、腕口及手臂相對比例。
- `images-17.jpeg` 與 `images-12.jpeg`：捕手手套的圓形厚墊、獨立拇指墊、較深掌袋；不共用一般五指手套輪廓。

另外搜尋核對 [Wilson 2026 A2000 1786 官方商品說明](https://www.wilson.com/en-us/products/spring-2026-a2000-1786-115-infield-baseball-glove-wbw102657)，只採用淺掌袋、H 型球擋的結構描述；未宣稱已播放網站影片。

## 製作與交付

- 可編輯來源：`assets/players/blender/baseball-gloves.blend`。
- 可重建來源：`scripts/build_blender_gloves.py`。
- 三個實際 glTF 2.0 binary 資產：`assets/equipment/field-glove.glb`、`pitch-glove.glb`、`catch-glove.glb`。
- 網頁直接讀取 GLB 的材質分組、法線、UV 與 HalfClose / Close 形變，沒有另用舊模型冒充 Blender 成品。
- 掌面、背面、邊緣厚度、腕口、球擋、指槽滾邊與短皮繩分開建模；閉合由四指側與拇指側夾合，腕口附近減弱變形。
- `glove-preview.html` 可直接查看三種類型、掌面、背面、旋轉與開合；人物預覽的「手套近景」檢查實穿。
- 模型中的尺寸、掌袋曲率及形變是根據照片的手工推估，非掃描或完整手指肌腱模擬。

## 檢查項目

逐一看正面、背面、側面與半閉／閉合；查看腕口、掌袋、虎口與手指是否相交；人物中查看手背是否只由腕口合理露出，球是否停留於實際掌袋後才換手。修正前後的觀察分開記錄，不以隱藏皮膚或遮擋鏡頭處理穿模。

### 第二輪輪廓修正

使用者指出初版自然張開狀態過平，與照片不符。重新把杯狀預彎直接烘入 Basis：一般／投手手套保留四指、拇指兩側內收，捕手手套保留圓形內彎；開合形變由此自然姿態開始。補上拇指內側厚墊與小指／掌跟滾墊。不是把預覽滑桿預先關一半來掩飾原模型。

第三輪依照片縮短四指側、增加橫向寬度，H 型球擋以扁平皮革帶建模；指縫縮回指部區域，避免把掌袋畫成整片長直線。比對自然張開、半閉與閉合，再接回人物檢查腕口和手背。

### 指尖與虎口修正

使用者指出指尖不應是方正厚板，球擋應位於虎口。重新把外皮厚度在輪廓邊緣逐漸收薄，指尖連接面由原約 5 cm 降至約 6 mm 再加圓弧滾邊，保留掌心內部容納手部的空間。H 型球擋下移並依拇指、食指的內側凹弧分別設置連接點，中間皮帶形成較低的曲面；投手封閉球擋同步調整。尺寸仍為照片推估。

### 球擋結構重新比對

重新實際查看使用者 images-18.jpeg 的正面照片：可見中央直向寬皮片、上緣橫向皮片，兩側以短皮繩固定到食指與拇指內側；不是幾條橫繩懸空跨過整個虎口。一般手套改為 I 形皮革球擋，刪除原 H 形構件與跨整幅的斜繩，改做左右分開的梯狀固定皮繩。球擋向上延伸於虎口凹口，尺寸與曲率仍為照片推估。投手封閉式與捕手球擋是不同型式，不能混用。
