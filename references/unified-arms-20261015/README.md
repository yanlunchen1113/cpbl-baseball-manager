## 系統修改

`pitch-arm-rig.js` 定義雙臂的肩、肘與前臂旋轉，與個人動作共用同一時鐘。人物投球由 `applyPitchArmRig` 單一入口負責；合手與返回準備姿勢以接觸錨點銜接，分手至收尾由同一 FK 軌跡控制。移除人物流程中舊伸臂、收臂、恢復控制的輪流覆寫。

手套側使用穩定的側向肘軸，消除 1800 ms 舊控制將手腕向下拉、肘部翻向上方的交接。肘屈曲限制在 0–135 度；前臂旋轉沿兩個 twist 骨與手腕分配。各球種的握法與旋轉設定保留，共用雙臂解算規則。

## 手動檢查紀錄

- 全段 0–4000 ms 每 40 ms 取樣，1600–1960 ms 每 20 ms 加密；最後調整返回合手後，3000–4000 ms 重新每 40 ms 取樣。
- 比對正面、側面、背面及左投鏡像，並切換 12 個球種選項查看 1800 ms。
- 預覽 1900 ms 出手時，球與手掌接觸點距離診斷為 0。
