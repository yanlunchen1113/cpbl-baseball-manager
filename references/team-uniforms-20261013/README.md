## 實作、觀察與推估

- 主客場兩套獨立版型，依比賽主客隊身分套用。
- 前背號讀取球員資料，前號在球員左腹、背號置中，沒有複製照片的示範號碼。
- 其他五隊未取得逐人可驗證的英文球衣背名，先用中文，沒有自行音譯；富邦保留先前官方資料與照片支持的縮寫。
- 背名離領口留白，與背號保留間距；弧度與位置由照片比對估計，仍需各隊實穿背照校準。
- Rajdhani Bold 是近似字型，不是各隊原版號碼字形。
- 胸字為內建 imagegen 依已查看照片重製的透明 atlas，不是官方字標原檔。遊戲資產 assets/uniforms/team-wordmarks-r1.webp，完整提示 wordmark-prompt.txt。格式優化為 WebP，程式映射圖片各區域。
- 細小袖章、帽字及品牌刺繡仍是簡化標記，並非精準逐項複刻。
- 圖案直接套原蒙皮，保留紮衣與黑皮帶；褲管與襪口配色匹配。
