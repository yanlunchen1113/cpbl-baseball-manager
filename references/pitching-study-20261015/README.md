## 實際影像觀察

- 分手、跨步、抬臂與轉軀幹同時進行；不能把它們拆成先站好、再把手臂搬到下一個姿勢。
- 需連續看肩—肘—手三點和胸腔朝向。世界座標中手在身後，不能直接推論為手肘反折或前臂自轉。
- 收尾時前腳承重，軀幹繼續前移，後腿抬起；拿球手隨身體減速。此例不能用來規定所有投手的回彈高度。

## 文獻支持的關節區分

ASMI 將投球分為準備、跨步、肩外旋蓄力、加速、減速、收尾。重要對齊事件是前腳接觸地面、最大肩外旋、球離手；其間是連續運動。

- **肩外旋**：上臂相對胸腔的旋轉，會帶著前臂呈現 layback。不能用肘部側折或前臂繞一整圈替代。
- **肘屈伸**：前臂相對上臂的彎曲。ASMI 綜述的參考值是前腳接觸時約 90° 屈曲，出手時仍約 25° 屈曲，並非鎖死成筆直。
- **旋前／旋後**：沿前臂的軸向轉動；**腕屈伸與尺橈偏**又是不同自由度。
- 論文報告的最大外旋約 170°涉及量測定義與肩帶／軀幹關係，不能直接填進 Blender 任意單軸，也不能要求每位投手達到相同數值。
- 動力鏈包含下肢、骨盆、胸腔與肩肘的時序；前腳支撐與軀幹傾斜必須一起重建。

## 對目前動畫的判斷（推論，尚非動捕量測）

1. `stadium3d.js` 的拿球手目前由少數位置控制點驅動 IK，肘平面也由手動曲線控制。把控制點由後側移到前側，只修正了路徑方向，不能據此宣稱投球機制正確。
2. 既有新版 1100 ms 前後截圖中，球仍接近頭側。需要重新量出肩、肘、手的相對位置與出手事件，確認肘伸展是否不足，而不是繼續憑畫面搬動手掌。
3. 肩外旋、前臂旋前、腕關節及軀幹轉動應分開處理，再檢查蒙皮；肘部離軸讀值為零，不能證明整條手臂符合人體運動。
4. 世界空間的「前／後」與軀幹局部空間的「前／後」要明確區分。個人化仍需以曾峻岳自身的側面及正背面連續影像校正。
