實際重新查看既有使用者錄影接觸表 references/equipment-walk-20261012/user-11.22.38-contact.jpg 的 4.4–5.1 秒影格：投球後投手直立看向本壘、放鬆恢復。這張接觸表並未呈現完整接回傳過程，不能據此宣稱已逐格量測接回傳。搜尋投手接回傳影像；既有 MLB 連結 https://www.mlb.com/video/ryan-weathers-called-strike-to-willy-adames-y9g6am 目前頁面顯示 Yelich 盜本壘片段，未播放，因此未作為接回傳關節證據。

程式確認：return 階段 applyDelivery 繼續讓投球手朝 readyHand 胸前位置移動，只有捕球後才覆蓋手套手，形成球尚未接到就已合手的效果。

改為接回傳階段獨立控制雙臂：投球手先放鬆在腰側，手套先迎球，1950ms 捕球，2180ms 之後投球手才接近手套開口；既有交替踏步返回投手板保留。上述毫秒值是遊戲時序估計，並非實拍量測。2450–2540ms 投球手由開口伸向球袋，2540ms 手掌握球點與球袋相合後才把球附著至投球手，再由開口取出。左右投鏡像使用同一流程。

## 下一階段資產

目前 MakeHuman 通用人物配合程序 IK／關鍵姿勢；臉部是共用模型與貼圖。Blender 可用於個別頭部形狀、皮膚貼圖、完整角色骨架及動畫片段，匯出 glTF/GLB 再由遊戲播放。先製作一位打者與一位投手範本、接上動畫片段與球具附著，再擴展人物。Blender 本身不會自動生成球員相貌或個人動作；仍需要逐人照片與影片參考，以及人工／腳本製作與修整。本次只查到電腦沒有 PATH 的 blender 或 /Applications/Blender.app，沒有安裝或聲稱已製作 .blend。
