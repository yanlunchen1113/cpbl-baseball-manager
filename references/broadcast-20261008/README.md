### v31.6 基礎手臂骨架校正

根因：原先將 MakeHuman 的 A 姿網格綁到簡化人物骨架，肩肘與掌心使用近似位置；前臂局部軸與動作使用的向下軸不一致，各動作又混用直接 Euler 旋轉與自由扭轉 IK。現在從原始網格 joint-l/r-shoulder、elbow、hand-2 輔助幾何計算實際關節位置，存入 human.json；以實際 A 姿建立逆綁定矩陣，再統一到動畫用的局部負 Y 軸。依肩肘掌平面建立彎曲軸，手肘只彎曲、不繞另外兩軸扭轉；屈曲限制 12–135 度並避開軀幹。待機、跑步、接球、滑壘、判決與傳球共用控制器，持棒雙手使用同一前方握點。這些限制與避碰包絡為遊戲模型設定，並非實測球員關節範圍。

技術參考：[MakeHuman 官方原始骨架](https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/rigs/default.mhskel)、[官方網格輔助關節說明](https://static.makehumancommunity.org/about/concepts/basemesh.html)。動作參考沿用上列使用者影片，未以新搜尋取代。真人模型仍是簡化骨架的通用人物，手指收握使用通用變形，尚未加入每種球路的個別指法與完整手腕動畫，不能宣稱所有接觸都已達實拍水準。

投球與第三人稱揮棒另以原錄影投球段（11.22.38 第 3 秒、11.18.54 第 2 秒）重新檢視跨步與蓄力。修正投球手臂過早上伸，加入分手後向後下方的擺臂階段、出手前手肘引導及持球可見；第三人稱揮棒加入髖部先轉、擊球延伸、肩帶收尾與依瞄準高度調整棒軌。保留使用者認可的第一人稱棒子與前臂呈現，兩者共用揮棒時間點（140 ms 擊球，740 ms 收尾，1050 ms 結束），左右鏡像共用規則。髖膝踝位置也從原網格量測，修正原模型腿長與簡化骨架不同造成的問題；鞋底另維持平面方向。提供 motion-preview.html 的左右投打、第一人稱及慢速／逐段時間控制，這是檢查工具，不會加入正常遊戲的按鈕。未使用動作捕捉素材，不宣稱已達到真人動捕品質。

手指補充：依原網格的各指節輔助定位點與原始權重製作收握 morph，投球持球時收握、出手後放鬆，第三人稱打者握棒時收握，捕手換手到回傳階段收握再張開。屈曲角度為通用動畫設定（非逐球種指法），模型掌心法線用來把持球中心放在掌面外側，貼地修正完成後重新附著。第一人稱握棒外觀維持原有呈現。

### v31.6 白線修正

重新查看使用者 11.18.54 錄影第 2 秒：打擊區為紅土地面的粉筆白線，沒有管狀邊框或自身投影。搜尋核對 [MLB 打擊區說明](https://www.mlb.com/glossary/rules/batters-box)，打擊區與壘線使用相同粉筆材料。原程式用圓柱建壘線與打擊區、圓管建本壘圓圈；現改零厚度三角帶與平面圓環，跟隨既有場地高度，不投射管狀陰影。細微高度偏移是防止同面閃爍的繪圖設定；線寬維持遊戲設定，未宣稱為每座球場實測。
