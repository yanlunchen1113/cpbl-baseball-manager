## 使用者錄影

「螢幕錄影 2026-10-08 上午11.26.16.mov」，137.5767 秒。使用 macOS AVFoundation 逐秒抽取 0–137 秒共 138 張畫面，完整檢視六張聯絡表；另放大 34、52、70、81、131 秒。原始錄影與抽取畫面保留本機，不上傳至遊戲網站。

- 0–10 秒：賽前球員鏡頭。
- 11–31 秒：裁判介紹與準備。
- 34–51 秒：左側打序表：隊徽、棒次、背號、姓名、守位、投打手。
- 52–64 秒：高位全場鏡頭，中央守位圖；CF 在上，C 在下，一壘在右。
- 66–69 秒：投手準備鏡頭。
- 70–80 秒：下方投手卡，登板／先發、勝敗、局數、防禦率。
- 81–89 秒：同一投手卡換第二頁，安打／全壘打、三振、四壞、WHIP。
- 90–91 秒：卡片縮回。
- 92–107 秒：投手與休息室鏡頭。
- 108–128 秒：主投球鏡頭、小型比分與投打資訊；資訊不蓋住投球動作。
- 129–134 秒：打者近景與下方球季卡。
- 135–137 秒：回主投球鏡頭。

這段錄影未出現大型 VS 開場卡；後續 11.18.05 錄影提供了實際對戰卡參考。打序與守位圖只在一局上、一局下播放。打者卡每次進入新打席，投手卡僅初登板／換投播放；避免每球重播。遊戲縮短卡片停留時間並提供略過。

- `/v1/players/logs`：球員、年份、聯盟類別、`DefendStationCode`。取得 2024、2025、2026 一軍與 2026 二軍已觀察到的守位；只採本人 HitterAcnt 相符且為具名守位的紀錄。不將「外野手」泛化成三個位置。
- 守位資格保留原始官網來源、年、場次與聯盟類別於 `data/broadcast-data.json`。沒有完整生涯史的球員採較保守的資格；不推測其他守位。DH 是不擔任防守的打線角色。

目前官方 API 的可驗證成績：打席、打擊率／被打擊率、上壘率／被上壘率、長打率／被長打率、三振率、保送率。沒有可驗證的 ERA／勝敗／滿壘、得點圈分項時，不用影片內其他球員數字或隨機數值冒充。單場卡實際可取得的欄位；賽季卡使用遊戲紀錄，滿壘與得點圈分開統計。
