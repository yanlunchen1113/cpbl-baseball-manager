## 實際觀察

范國宸：右打、握棒在後耳附近，前左膝明顯抬起蓄力；約 2.4–2.6 秒前脚落地接腰部旋轉；2.6–2.8 秒延伸；3.0–3.4 秒仍雙手持棒，棒子在高處完成收棒。這個初版保留雙手收棒，不把別人的單手釋放套給他。

曾峻岳：右投，17.0 秒抬左膝、雙手位置較低；17.2 秒分手跨步；17.4 秒手套前伸，投球臂向下往後；17.6 秒骨盆打開、前臂抬起；17.8 秒投球臂往手套側收、後腿抬起；18.2 秒恢復平衡。

官方正面照片：范國宸臉形較長、頰部及下顎較寬柔；曾峻岳臉形較緊湊、眉較平厚、嘴唇較飽滿。帽下髮線和頭頂沒有完整證據。

## 推估與製作範圍

- 臉形為原有 CC0 MakeHuman 頭部的照片參考 shape key，非掃描或精準肖像重建。
- 頭部貼圖由影像工具以官方照片與只含頭部的 UV 版型產生；已做模型 UV 對位。不得把生成貼圖當實拍。
- 身體仍使用原有 MakeHuman 網格。Blender 工程含兩人的骨架、頭部 shape key、動作控制曲線、手腳 IK 編輯示意。
- Blender `AUTO_CLAMPED` 曲線按 20 ms 匯出，再交給現有遊戲 IK，維持握棒、出手點與地面接觸。時間、角度、關節距離是人工推估，並配合現有遊戲時序，非逐格動作捕捉。
- Blender 內 IK 動作是可編輯工作底稿；場上接觸與裝備適配由現有執行層完成。還未全面改成 glTF / AnimationMixer 動作管線。
- 投手接回傳球繼續採用獨立接球、手套口取球與走回投手板的流程。

## 檔案

- `assets/players/blender/fubon-individual-prototypes.blend`：本機可編輯工程，貼圖已打包。
- `scripts/build_blender_characters.py`：可重建工程和匯出資料。
- `data/character-authoring.json`：人工編輯控制點與形狀參數。
- `assets/players/characters/manifest.json`：實際 Blender 曲線採樣和頭部頂點差值。
- `character-preview.html`：正面／側面臉部、專屬動作、蓄力抬腿、時間滑桿。

逐格截圖保存在本目錄。`tseng-16.0.png` 是切鏡到跑者的畫面，未用作投手動作參考。

## 初版限制

個別人物功能目前只在 `character-preview.html` 啟用。臉部生成貼圖仍需手工雕修和精準 UV 清理，尤其眼周、唇部和帽下髮線；此版供造型與動作方向檢視，尚不視為最終肖像。

## 32.0 preview2：蓄力接入完整揮棒

再次查看已保存的官方影片逐格畫面（2.4 秒前腳落地前的姿勢），沿用前述觀察。修正原預覽「專屬動作」直接從揮棒開始、蓄力只在獨立按鈕播放的接線錯誤。完整段落為 0–1500 ms 抬前腳蓄力並落腳，1500–2800 ms 轉腰揮棒及雙手高位收棒。前腳落地後不再套入通用揮棒的小幅抬腳。這些時間是遊戲製作時序，不是影片測量值。Blender 骨架工作底稿亦接成同一段落。

同版再對照曾峻岳 17.8、18.2 秒逐格截圖：17.8 秒後腳高抬、投球手向下跟隨；18.2 秒投球手已沿投球側回升到肩以上，手套側仍向下外展，後腳尚未完全落地。補上「向下跟隨 → 投球側回升 → 落腳」；空中後腳不再被當成已著地的支撐腳來降低骨盆。高度與世界座標屬作者推估，保留物理模型的實際出手點。

### 造型回修

再對照本目錄官方正面照片的窄眼、自然眼皮及球帽比例，以及使用者提供的富邦主場實穿照。取消整張生成五官貼圖在模型上的套用，保留原始頭部 UV；減弱頰顎膨脹，調整眼皮開口，使用既有眼窩內表面呈現虹膜，取消額外凸出的外加眼球。這是恢復正常解剖的工作底稿，尚未完成個別肖像。

球帽改為較貼頭的分段帽冠，帽簷縮短、改為兩側向下的曲率，帽徽貼近前面帽冠；頭盔保持獨立硬殼形狀。胸前 momo 小標誌從肩頸區下移至上胸；袖章由袖管正面轉到上臂外側並稍下移。小徽章圖樣仍是簡化近似，位置以照片對照修正。球具與球衣適配目前仍在執行層；尚未完成 glTF 全流程轉換。

袖管 UV 的圓周長與軸向長度不同；袖章繪圖需作約 1:4 的 atlas 比例補償，讓實際 3D 上臂的徽章接近圓形，避免原先被拉成橢圓。

帽簷根部沿帽冠底緣的同一橢圓曲線與高度建立，並補齊下緣厚度；取消根部額外下彎造成的兩側縫隙。

### preview3：連續肘部解算

取消所有人物的候選肘部方向硬選取，改為碰撞代價的連續加權，再投影至可解算的彎曲平面。接近抵消時使用作者提供的肘部方向；胸前腕部避碰改为橢圓徑向推離，避免 z 正負翻面；取消出手前後肘部 z 的瞬時切換。曾峻岳補上準備、分手、舉肘、出手、向下跟隨與再次抬手的連續肘部曲線。仍使用原 12–135 度肘屈曲限制及原骨長。這些控制點是參考影片的手工推估，不宣稱完整人體肌肉或關節模擬。

人物預覽在投球 1100 ms 出手後切入球飛行階段，球依實際出手點離手，避免整段被視作 windup 而將球一直留在投球手。

握棒手腕的旋轉角展開為連續角度後再套用 ±70 度限制，避免 atan2 在 ±180 度邊界變號後，手腕由一側限制瞬間跳到另一側。腕部微調採圓柱棒身軸線最近方向，避免反平行軸的四元數翻面；屈伸修正保持原約 20 度限制。

### preview4：雙前臂與完整揮棒時間軸

再次實際查看保存的范國宸 2.2、2.4、2.6 秒與曾峻岳 17.6、17.8 秒逐格畫面。范國宸前腳下降時身體已有蓄勢與轉動，落腳、骨盆啟動、手部跟隨是重疊連續的過程。改成一條全身曲線，同時控制骨盆、胸腔、握棒、棒頭、前腳下降與跨步、後膝方向；取消人物參考預覽中原來的通用擊球位置強制拉手。出力與擊球的時間為手工重建，非 mocap。

曾峻岳兩側前臂均限制在肩到手連線的解剖外側彎曲平面；作者偏好肘部方向只能作有界修正，不能帶著前臂繞手臂軸一整圈。此限制僅用於該個別投手動作。

手套手另修正原先分手後仍把腕部拉到肩旁的目標：用相對手套側肩膀的連續伸手曲線，分手時向本壘方向伸展，再隨出手回收；避免為了到達肩旁過近的腕部目標而讓前臂折回。

移除出手後前 40 ms 讓投球手繼續追自由飛行球的第二次 armTo 覆寫。這會在球高速離手時拉動手臂，再於 40 ms 切回作者收尾；出手後應保留收尾曲線，不能以球的位置重新解算手臂。另加前後動作視角切換，便於查看兩手肘腕。
